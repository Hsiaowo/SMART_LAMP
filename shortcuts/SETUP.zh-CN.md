# iPhone 快捷指令：连接软件 MVP

手机与电脑在同一个可互访的家用网络，电脑后台运行在 8765。`127.0.0.1` 只代表当前设备，手机上不能用它连接电脑。

从项目 `config.local.json` 取 `server_url` 和 `admin_token`。后端令牌不放 URL 参数。下文以 `http://电脑局域网IP:8765` 表示，替换为真实地址。

## 1. 设置唤醒灯

在“快捷指令”新建一个快捷指令，命名“设置唤醒灯”：

1. 添加“询问输入”，类型选择日期与时间，提示“几点起床”。
2. 添加“格式化日期”，输入刚才的时间；使用 ISO 8601（必须包括时区）。如果使用自定义格式，可用 `yyyy-MM-dd'T'HH:mm:ssXXX`，并在首次测试时核对输出带 `+07:00` 这类偏移。
3. 添加“生成 UUID”作为 `request_id`。若你的版本名称不同，可以搜索 UUID；每次新设置使用新 ID。
4. 添加“URL”：`http://电脑局域网IP:8765/api/v1/wake-plans`。
5. 添加“获取 URL 内容”，展开设置，方法 POST。
6. 请求头添加 `Authorization`，内容是 `Bearer 你的admin_token`；Bearer 与令牌之间有一个空格。
7. 请求体选择 JSON，添加以下字段。数值必须设置成“数字”，不要用数字字符串。

| 字段 | 类型 | 值 |
| --- | --- | --- |
| request_id | 文本 | 生成的 UUID |
| wake_at | 文本 | 格式化日期结果 |
| ramp_seconds | 数字 | 调试 20；正常 1200 |
| hold_seconds | 数字 | 调试 10；正常 1200 |
| peak_percent | 数字 | 100 |

8. 使用“从词典获取值”读取回复的 `plan_id` 和 `sync_url`，显示“后台已接收，正在等待设备保存”。
9. 可用“保存文件”把 `plan_id` 保存到快捷指令自己的文件，例如 `SmartLamp/current-plan.txt`，供修改/取消使用；首次文件权限按 iPhone 提示设置。

不要把后台已接收直接显示成“三灯/实物已设置成功”。

首次建议设置至少两分钟后起床，用 20 秒渐亮方便观察。手机上的标准日期格式、UUID 与请求动作名称以实际 iOS 界面为准，本项目尚未在你的 iPhone 上逐项点选验证。

## 2. 查看同步结果

URL：`http://电脑局域网IP:8765/api/v1/state`，方法 GET，带相同管理员请求头。

- `hardware_saved`：实物保存当前版本的数量。
- `hardware_ready`：在线、已保存、时间有效的实物数量。
- `hardware_target`：当前配置的实物数量，最小系统为 1。
- `simulator_ready`：电脑模拟器就绪数量，独立显示。

可以“显示结果”查看这些字段；初版也可以直接打开电脑局域网控制页。不要在快捷指令里整夜 Wait 或设置无限轮询。

## 3. 修改

从保存的文件读取 `plan_id`，请求：

```text
PATCH http://电脑局域网IP:8765/api/v1/wake-plans/实际plan_id
```

请求头同上，JSON 与新建相同，但使用新的 `request_id` 和完整的新时间、渐亮、保持、亮度。初版 PATCH 要求完整配置。

如果旧计划已被新建操作替换，旧 ID 返回 404。这时重新读取网页/状态中的当前 `snapshot.plan_id`，或直接新建。

## 4. 取消

读取保存的 `plan_id`，方法 DELETE，带管理员请求头，不需要 JSON 请求体：

```text
DELETE http://电脑局域网IP:8765/api/v1/wake-plans/实际plan_id
```

取消也要等设备保存新版本。设备离线时，原计划可能继续执行；可以在网页核对状态。

## 5. 当前限制

此快捷指令在设置时把完整计划交给设备，iPhone 不用在起床时运行。它不会自动监听原生时钟里的任意编辑动作。

调试用局域网 HTTP 不提供加密，不发送新闻服务密钥，不在公网映射端口。正式 HTTPS/MQTT 升级按完整方案进行；需要远程设置时再配置安全接入。
